# Geometry and corpus lane — proposed plan

Treat geometry as a versioned, read-only artifact producer plus a small pure numerical library. Start with direct map-space scoring; an explicit full target and residual prior are optional experiments. This isolates the scientific question of residual plausibility from the sampler, hardware backend, and UI. This note follows the supplied research brief; no corpus, encoder checkpoint, or backend is selected, downloaded, or published.

**Orthogonal workflow and contracts.**

| Component | Owns | Boundary other lanes can use immediately |
|---|---|---|
| Corpus builder | Text unit, provenance/license metadata, deterministic cleanup, grouping/deduplication, train/dev/test split | `CorpusRecord{id,source_id,group_id,text,embed_text,text_hash,split,metadata}` and ordered corpus fingerprint |
| Frozen encoder adapter | Exact model revision, tokenizer revision, task/prompt, pooling, normalization, truncation, dimensions, precision | `encode_texts(texts)->EmbeddingBatch{vectors,encoder_id,truncation_flags}`; finite `[n,d]` floating vectors in declared order |
| PCA artifact builder | Fit on training corpus only; centered, unwhitened 2D PCA; fixed axis orientation and metric | `MapArtifact{map_id,encoder_id,corpus_id,mu[d],V[d,2],metric_S[2,2],variance,fit_ids,display_bounds}`; `project(e)->y` |
| Geometry objective | Target validation, map loss, optional residual score, diagnostics | `TargetSpec{target_id,map_id,y[2],metric_id,tolerance,prior_id?,seed?}`; `score_embeddings(e,target)->{map_error,residual_score?,support_diagnostics}` |
| Residual prior | Training-only residuals and explicitly versioned conditional estimator | Optional `sample(y,seed)->{full_target,diagnostics}` and/or `penalty(e,y)`; sampler never required to consume a full target |

Expose one integration entry point, `score_texts(texts,target)->{embeddings,points,map_errors,diagnostics}`, composing the frozen encoder and pure geometry scorer. The guidance lane receives a target, map arrays, and objective; the runtime lane receives capability flags and array/tensor shape contracts. Evaluation owns the hidden test witnesses and hard-text verification. UI consumes a small JSON view of map points, display transform, density diagnostics, target, and measured generated point; it never fits PCA or derives scientific distance from screen pixels. Derive `map_id` from corpus, encoder preprocessing, fitted projection, and metric fingerprints. Requests and results carry `map_id` and `encoder_id`; reject mismatches. Changing encoder, prompt, normalization, or corpus fit creates a new map rather than silently moving saved clicks.

Keep two encoder contracts separate. **Score-only** needs text-to-vector access and can support any tokenizer or inference backend; the input to final verification is always decoded text passed through the normal encoder tokenizer. **Differentiable** is an additional capability: `encode_input_vectors(vectors,mask,positions,prompt_context)->embeddings`, preserving the same pooling and normalization while retaining derivatives to inputs and freezing parameters. A distinct generator-to-encoder bridge declares its tokenizer pair, supported token coverage, special-token/mask policy, approximation, and backend. Equal vocabulary sizes do not establish compatibility. Unsupported gradients are a capability failure, never a fallback represented as equivalent guidance. Do not tie this interface to a framework's inference convenience function. Sentence Transformers exposes independent prompt, precision, normalization, and truncation settings; these therefore belong in the encoder fingerprint. [Official encoder API](https://sbert.net/docs/package_reference/sentence_transformer/model.html).

Preserve original text separately from `embed_text`; make whitespace/Unicode cleanup explicit and avoid unrecorded semantic edits. Group source documents before splitting so chunks and duplicates cannot cross splits. Choose a generation-length policy that fits the encoder after its prompt and special tokens; record every truncation. An ignored tail can make the score reward a prefix while the full output deteriorates. For a real pilot, use the brief's approximately 1,000–2,000 approved texts after exclusions; leave corpus source, genre, languages, and license choice to the project decision.

**Geometry and residuals.** Fit `y=Vᵀ(e−mu)`, `VᵀV=I`, with `whiten=false`; save the actual fitted arrays, solver/settings, and a sign convention. PCA centers features but does not scale them automatically, and whitening changes coordinate scaling. [Official PCA API](https://scikit-learn.org/stable/modules/generated/sklearn.decomposition.PCA.html). Set the primary metric explicitly: propose `S=I` in PCA coordinates and an isotropic viewport transform. Report variance-normalized distance separately if desired; never silently substitute it for displayed distance. Freeze `S`, tolerance, and display bounds before comparisons. A useful scale-free secondary error divides raw distance by one frozen training-set map-distance scale.

The algebraic completion `e=mu+Vy+r`, `Vᵀr=0`, has the clicked projection but is not necessarily a natural-text embedding. A unit-norm encoder adds a sharper constraint. **Derived here:** write `a=Vᵀmu+y` and `e=Va+u`, with `Vᵀu=0`. Then unit norm requires `||u||²=1−||a||²`. Thus `||a||>1` is impossible even in the ambient unit sphere; passing this test does not establish textual reachability. Normalizing an arbitrary completed vector generally moves its projection. A sphere-preserving construction can choose a residual direction and the required radius, but that transformation changes the empirical residual prior and must be reported.

Compare residual policies independently: (0) no explicit residual penalty; (1) zero centered residual as an algebraic diagnostic; (2) local empirical residual samples or weighted local mean; (3) shrinkage/low-rank conditional Gaussian, only after simpler policies. Policies 2–3 improving naturalness/diversity are **hypotheses**, not established outcomes. With `k` local points, centered covariance rank is at most `k−1`; unrestricted high-dimensional conditional covariance is unjustified here. Shrinkage addresses conditioning, not whether a Gaussian is a good model. [Official covariance guidance](https://scikit-learn.org/stable/modules/covariance.html#shrunk-covariance). Use training-only neighborhoods, expose effective sample size, and return sparse-support/degenerate diagnostics. If priors enter gradient guidance, hold local weights fixed per target or explicitly smooth their dependence; hard nearest-neighbor switches are not differentiable.

Low 2D error can coexist with poor full-space semantics or repetitive/adversarial text. PCA variance is not semantic fidelity. Corpus hull and density describe observed support; outside-hull points are not proven impossible, and inside-hull points are not proven reachable. Near-degenerate leading eigenvalues can rotate axes across fits even when a sign rule is stable; artifact identity, rather than a seed alone, protects saved targets.

**Minimum useful artifact and small contract checks.** First deliverable should be a self-contained geometry fixture bundle: manifest, a dozen authored text records paired with explicitly synthetic vectors, saved map arrays, projected points, three target cases, and expected numerical scores. Label it nonsemantic. It lets UI, runtime, and evaluation integrate without downloads. The first scientific bundle replaces only the fixture data with approved real embeddings, includes training/dev/test manifests, explained-variance and truncation reports, and a scorer for actual text. Store numerical arrays as NPZ/NPY and interoperable metadata as JSON/JSONL; no framework-specific serialized model object is required.

Six meaningful contract checks suffice initially:

1. Save/load preserves map projections, row IDs, hashes, and target scores within declared numeric tolerance; reject wrong encoder/map IDs and nonfinite/wrong-shaped vectors.
2. A tiny known PCA fixture checks centering, axis order, orthonormality, and out-of-sample projection; changing an omitted residual preserves coordinates.
3. Unit-norm toy cases check the shifted sphere bound and demonstrate that arbitrary post-completion normalization can move a click.
4. Duplicate/source groups remain disjoint across splits; test witness IDs cannot enter PCA fit or residual-neighbor state.
5. For differentiable adapters only, hard encoder-token input reproduces the ordinary text path on declared equivalent tokenization; finite differences check an input gradient through pooling, normalization, and map loss; parameter weights remain frozen. Tokenizer bridges additionally report one-hot mismatch rather than claiming universal parity.
6. UI pixel-to-map round trip and server map loss agree on the same target; integration verifies the generated point comes from decoded-text re-embedding, not a soft surrogate.

**Staged experiment plan.**

1. Freeze fixture contracts and the primary distance/tolerance definition. Keep gradient capability optional so every lane can progress.
2. Build one approved corpus/encoder/map bundle. Inspect duplicate leakage, truncation, variance retained, 2D versus full-space neighbors, and residual norms before generation. Define a small stratified target panel: held-out text projections with hidden witnesses, dense-region interpolations, sparse regions, and ambient-sphere failures. An interpolated target is an exploratory case, not a known reachable one.
3. Establish retrieval and score-only generation/reranking baselines under a fixed output-length and wall-clock budget. Retrieval is a diagnostic ceiling/reference over the available corpus, not success at novel generation. Do not expose held-out witness text to prompting or retrieval. Record hard map error, tolerance success rate, coherence, repetition, diversity, full-space neighbor behavior, and runtime.
4. Compare optional gradient adapters against the same score-only baseline with paired targets/seeds and matched wall-clock budgets; record soft-to-hard gap and tokenizer-bridge coverage. Change no residual policy during this comparison.
5. Ablate residual policies with the winning feasible generation method fixed. Tune on dev targets, then freeze settings for test. Report per-target paired results and uncertainty, not just an average; continue only when hard-text improvement survives quality and latency constraints. Compare a second encoder by rebuilding its map and using corresponding held-out texts/relative target strata, never by reusing numeric coordinates.

All experimental choices above are proposals. Corpus selection, genre/length, tolerance, quality rubric, encoder access, and latency budget remain project decisions; none prevents agreement on fixture contracts now.
